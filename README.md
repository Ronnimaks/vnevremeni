# Вне времени — сайт музыкально-поэтического клуба

Сайт клуба «Вне времени» (Москва): резиденты, афиша вечеров, галерея, отзывы, бронирование билетов.

**Открытая версия:** https://ronnimaks.github.io/vnevremeni/

## Стек

Vite 8 + React 19 + Tailwind 4 + framer-motion. Чистый статический фронтенд, без бэкенда и базы данных.

Настройка Tailwind живёт в `src/index.css` в блоке `@theme` — файл `tailwind.config.js` не подключён и ни на что не влияет.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
npm run lint     # oxlint
```

## Что где

| Путь | Что это |
|---|---|
| `src/components/` | Секции страницы, по файлу на секцию |
| `src/data/residentsData.js` | Девять резидентов: имя, роль, биография, соцсети |
| `src/components/SocialIcons.jsx` | Иконки соцсетей (Simple Icons, CC0), общие для резидентов и подвала |
| `public/images/gallery/` | Фото с вечеров: полные 1600px и превью 800px, WebP |
| `public/videos/` | Видеоотзывы, H.264 mp4 с faststart |
| `src/assets/fonts/` | Inter и Playfair Display, локально (SIL OFL) |

Шрифты лежат локально, а не тянутся с Google Fonts: сайт открывают из России, и чужой CDN там работает нестабильно.

## Незакрытое

- **Оплата не подключена.** Экран СБП в форме бронирования — предварительный вид, реквизитов в коде нет и быть не должно до отдельного решения заказчицы.
- **Заявки никуда не уходят.** Бэкенда нет; место для подключения отмечено `TODO` в `BookingModal.jsx`.
- **Заглушки, ждущие данных от заказчицы** помечены в коде комментарием `ЗАГЛУШКА`: имя автора второго видеоотзыва, личные Instagram авторов отзывов, тексты цитат.
- **Афиша вымышленная** — даты, площадки и цены в `Events.jsx` придуманы при вёрстке, их надо заменить настоящими.
- **Админ-панель** открывается только по адресу с `?admin`. Это сокрытие от случайного посетителя, а не защита: бэкенда нет, любой фронтендовый пароль вскрывается за минуту.

## Деплой

Ветка `main` — исходники, ветка `gh-pages` — собранный `dist/`.

```bash
npm run build
git worktree add gh-pages-tmp gh-pages
# скопировать содержимое dist/ в gh-pages-tmp/, закоммитить, запушить
```
