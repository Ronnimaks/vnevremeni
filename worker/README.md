# Обработчик заявок «Вне времени»

Cloudflare Worker: принимает заявку из формы бронирования на сайте и пересылает её
организатору сообщением в Telegram.

Зачем он нужен: чтобы токен бота не лежал в коде сайта. Всё, что попадает в браузер,
может прочитать любой посетитель — токен из фронтенда украли бы в первый же день.
Здесь токен хранится в секретах Cloudflare и наружу не выходит.

## Что происходит по шагам

1. Гость заполняет форму → сайт делает `POST` сюда со статусом `new`.
   Заявка уходит **до оплаты** — если гость закроет вкладку, она всё равно у организатора.
2. Гость нажимает «Я оплатил(а)» → второй `POST` со статусом `paid`.
3. Если гость вернулся и поправил данные → `POST` со статусом `update`, номер заявки тот же.

## Развёртывание

Нужен аккаунт Cloudflare (бесплатного тарифа хватает с большим запасом:
100 000 запросов в сутки).

```bash
cd C:\POET\worker
npm install
npx wrangler login

# Создать бота: написать @BotFather в Telegram, команда /newbot, получить токен.
# Узнать chat_id: написать боту любое сообщение, затем открыть
# https://api.telegram.org/bot<ТОКЕН>/getUpdates и взять оттуда message.chat.id
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID

npx wrangler deploy
```

После развёртывания wrangler покажет адрес вида
`https://vnevrem-booking.<аккаунт>.workers.dev`. Этот адрес прописывается в сборке сайта
как переменная `VITE_BOOKING_ENDPOINT`.

## Домены

`ALLOWED_ORIGINS` в `wrangler.toml` — список доменов, с которых Worker принимает заявки.
Запрос с чужого домена получает 403. **После покупки домена его нужно туда добавить**,
иначе форма перестанет отправлять заявки.

## Защита от спама

- скрытое поле-ловушка: люди его не видят, боты заполняют — такие заявки отбрасываются молча;
- проверка всех полей: длина имени, 11 цифр в телефоне, разумное число билетов и сумма;
- ограничение размера запроса (2 КБ);
- приём только с доменов из белого списка.

Капчи нет: для клуба такого размера это лишний барьер для гостя. Если пойдёт спам —
добавим Cloudflare Turnstile, он бесплатный и невидимый.

## Проверка

```bash
curl -X POST https://vnevrem-booking.<аккаунт>.workers.dev \
  -H "Origin: https://ronnimaks.github.io" \
  -H "Content-Type: application/json" \
  -d '{"kind":"new","bookingId":"TEST","name":"Тестов Тест","phone":"+7 (999) 000-00-00","tickets":1,"total":900,"eventTitle":"Проверка"}'
```

Ответ `{"ok":true}` и сообщение в Telegram означают, что всё работает.
